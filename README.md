# 深渊构筑（暂定名）· 玩法原型 v15

竖屏 2D 像素地牢 Roguelite：单手全自动战斗，9 个职业，4 章 × 3 关 × 6 个地牢，团本式首领战，英雄联盟斗魂竞技场风格的海克斯构筑。

**在线试玩：** https://lurenyuanshi.github.io/abyss-build/?v=15

## 流程
主页 → 深渊地图（选章节与关卡）→ 选职业 → 出发。每章是一局连续冒险：关卡打完自动进入下一关，等级与海克斯保留；所有角色开局都是 1 级；**海克斯只在本关有效**，进入下一关清空重选（等级保留）。

## 操作
- 手机：单手即可，自动走位、普攻、放技能；大招点右下角或自动释放；按住屏幕拖动可接管走位
- 电脑：WASD 接管走位，1/2/3 选卡
- 左下角 ⬡ 按钮：查看已选海克斯与流派进度（打开时暂停）
- 普攻为三段连击（1.2 秒不攻击则重置），弹道、命中与首领技能全部为贴图特效

## 内容
- **章节**（参考团本结构，每章 3 关：前两关小首领，第 3 关章节首领，每关第 3 间为精英）
  - 第 1 章 炽焰山脉：熔火骷髅、熔岩犬、熔岩史莱姆、火焰小鬼｜黑鳞龙后 → 赤炎巨龙 → **熔火君主**
  - 第 2 章 黑石龙巢：龙人战士、雏龙、岩石史莱姆、黑龙教徒｜色彩龙王 → 双极雷像 → **黑翼领主**
  - 第 3 章 亡者要塞：骷髅、食尸鬼、瘟疫史莱姆、骷髅弓手｜缝合憎恶 → 瘟疫舞者 → **冰霜巫妖**
  - 第 4 章 深渊神殿：虚空骷髅、暗影蝠、眼魔、深渊术士｜孢子君主 → 千眼之神 → **深渊君王**
  - 首领机制参考经典团本（熔岩潜地、深呼吸、分区舞蹈、极性、旋转凝视、必然厄运、冰霜冲击、双色吐息、职业召唤、燃烧刺激），名字与形象原创；每个技能都有专属特效
- **职业 9 个**（每个独立造型）：近战 剑士 / 斗士，刺客 刺客 / 忍者，射手 法师 / 工程师 / 射手，治疗 吟游诗人 / 圣骑士；技能与大招各不相同
- **海克斯**：每清一个地牢选一次（每关 5 次：白银 → 白银/黄金 → 黄金 → 黄金 → 棱彩），卡框颜色随品质变化
  - 按职业组织：每个职业 3 个流派 × 5 张（只属于该职业），集齐 2 / 3 件激活羁绊
  - 通用海克斯按 6 类定位归类：近战物理（剑士、斗士、刺客）、远程物理（射手、工程师、忍者）、远程法术（法师）、近战法术（预留）、近战治疗（圣骑士）、远程治疗（吟游诗人），外加少量全职业通用；命名参考英雄联盟：回归基本功、歌利亚巨人、坦克引擎、重量级打手、终极唤醒、超凡邪恶、无限递归、疯狂科学家……
  - 去掉了概率触发，改为固定节奏（如“每第 3 次普攻”）；强力卡带副作用，棱彩无副作用；有前置条件的卡只在拥有基础机制后出现
- **回血**：小怪约 6% 掉落爱心，精英 / 首领必掉，靠近自动吸附
- **地图**：房间 + 走廊、镜头锁定房间、小地图；每关环境与首领对应（熔岩、龙巢、瘟疫、冰封、虚空……）并带环境粒子
- 主页与深渊地图为像素插画；8-bit 合成音乐音效

## 首领团本机制（v15）
- 黑鳞龙后：65% 起飞（无敌、雏龙、深呼吸扫场、火球），40% 落地后恐惧咆哮 + 熔岩喷发
- 赤炎巨龙：开场只有 30% 血、红龙精华（大招冷却减半）、燃烧刺激；熔火君主：拉格纳罗斯之怒击退、潜入熔岩召唤烈焰之子（全灭才浮出）
- 色彩龙王：每场随机 2 种吐息（火 / 冰 / 时间流逝昏迷 / 腐蚀酸液）+ 龙血痛苦随机减益，20% 狂乱；双极雷像：极性转换 + 离太远会被球状闪电集火
- 黑翼领主：开场龙人军团（无敌）→ 现出巨龙真身，职业召唤 / 暗影烈焰 / 恐惧，20% 骸骨复苏
- 瘟疫舞者：定时上平台快速舞蹈；冰霜巫妖：P1 亡灵大军（无敌）→ P2 寒冰箭 / 冰霜冲击 / 暗影裂隙 → 45% 冰冠守护者
- 孢子君主：必然厄运（叠加）、孢子、坏死光环（无法回血）；千眼之神：凝视扫射、眼棱、巨爪触须，50% 显露真身
- 所有首领施法时头顶红字技能名，小怪蓄力 / 瞄准时头顶红色感叹号

- 快速怪（熔岩犬、雏龙、食尸鬼、暗影蝠）蓄力后扑击；史莱姆死亡分裂（瘟疫史莱姆留毒池）
