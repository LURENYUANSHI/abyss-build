# 深渊构筑（暂定名）· 玩法原型

竖屏 2D 像素地牢 Roguelite 原型：走位 + 自动普攻 + 1 个技能 + 1 个大招，怪潮割草，升级三选一海克斯。

**在线试玩：** https://lurenyuanshi.github.io/abyss-build/

## 操作
- 手机：拖动屏幕任意处移动，右下角 ⚡ 技能 / 大招
- 电脑：WASD 移动，J 技能，K 大招，1/2/3 选卡
- 链接加 `?boss`：6 秒后直接出 Boss

## 内容
- 海克斯 22 个、6 个流派，每轮三张同品质（稀有 / 史诗 / 传说），集齐同流派 3 张激活羁绊；每张卡可模拟看广告刷新一次
- Boss「骸骨领主」：冲锋 / 弹幕 / 重砸，均有预警，半血狂暴；击败后奖励一轮传说海克斯
- 大招带角色特写演出
