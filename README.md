# 深渊构筑（暂定名）· 玩法原型 v7

竖屏 2D 像素地牢 Roguelite：单手全自动战斗，9 个职业，12 关 × 6 个地牢，首领机制战，三选一海克斯构筑。

**在线试玩：** https://lurenyuanshi.github.io/abyss-build/

## 操作
- 手机：单手即可。角色自动走位、普攻、放技能；大招可点右下角或自动释放；按住屏幕拖动可接管走位
- 电脑：WASD 接管走位，1/2/3 选卡
- 流程：主页 → 关卡选择（12 关，通关解锁下一关，记录最佳）→ 选职业 → 出发；每关是独立的一局（约 2.5 分钟）
- 测试参数：`?lv=5` 解锁并直接到第 5 关选职业，`?boss` 直接进入首领房

## 内容
- **职业 9 个**，分近战 / 远程：
  - 近战（挥砍无弹道，受伤 -20%）：剑士（挥剑 + 剑气）、斗士（纯近战范围挥拳 + 吸血）、刺客（双刺）、圣骑士（圣锤 + 审判）
  - 远程：法师（法球）、工程师（速射）、射手（长弓）、忍者（弹射手里剑）、吟游诗人（追踪音符）
  - 每个职业技能、大招效果都不同（万剑归宗 / 星辰陨落 / 崩山拳 / 轨道炮击 / 天穹箭幕 / 千影杀 / 百鬼夜行 / 终焉交响 / 神恩降临）
- **职业流派**：每个职业 3 个流派（如法师：奥术 · 火焰 · 冰霜；斗士：震地 · 嗜血 · 狂暴），每个流派 5 张卡，2 件 / 4 件羁绊；另有 12 张通用海克斯
- **副作用**：分裂、连珠箭、连斩等收益卡带代价（如每枚伤害 -40%），玻璃大炮、狂热等通用卡同理；棱彩品质无副作用
- **地图**：每关 6 个房间由走廊连接；战斗时镜头锁定整间房间，走廊中平滑跟随；震动只保留大招、首领重击等大事件，可在主页关闭
- **首领**：12 个大首领 + 12 个精英首领，技能组合各不相同；大首领机制参考经典团本玩法思路，名字与形象原创。半血狂暴，限时狂怒（越后面的关卡越早狂怒）
- **经验**：击杀直接获得
- **难度曲线**（随机选卡自动模拟）：精英约 25–45 秒、大首领约 30–50 秒；通关率 第 1 关 100% → 第 4 关 96% → 第 8 关 89% → 第 12 关 78%
- 8-bit 合成音乐与音效，左下角 ♪ 静音
