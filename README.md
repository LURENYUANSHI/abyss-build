# 深渊构筑（暂定名）· 玩法原型

竖屏 2D 像素地牢 Roguelite 原型：单手操作、全自动战斗（普攻 + 1 个技能 + 1 个大招），怪潮割草，房间内有障碍物，升级三选一海克斯。

**在线试玩：** https://lurenyuanshi.github.io/abyss-build/

## 操作
- 手机：单手即可，全自动战斗（技能、大招自动释放，大招也可点右下角手动放）；按住屏幕拖动可接管走位
- 电脑：WASD 接管走位，1/2/3 选卡
- 链接加 `?boss`：直接从 1-5 首领战开始

## 内容
- 海克斯 24 个、8 个流派（暴击 · 雷电 · 毒伤 · 召唤 · 护盾 · 连击 · 吸血 · 剑阵），以强化普攻为主，每轮三张同品质（稀有 / 史诗 / 传说），同流派 2 张、3 张分别激活羁绊；每张卡可模拟看广告刷新一次
- 关卡：每章 5 关（第 5 关首领战），每关怪数有限，清完自动吸经验、开门、走向下一关；3 套房间布局轮换，越往后怪越多越硬
- 大招 5 秒冷却，可点右下角释放，也会自动释放
- 8-bit 合成音乐与音效（地牢曲 / Boss 战曲），右上角 ♪ 可静音
- Boss「骸骨领主」（每章第 5 关）：冲锋 / 弹幕 / 重砸，均有预警，半血狂暴；45 秒内打不死会狂怒（全屏伤害），考验构筑输出；击败后奖励一轮传说海克斯
- 大招带角色特写演出
